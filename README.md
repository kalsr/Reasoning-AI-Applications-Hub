CogniReason AI Suite is a Streamlit-based demo application by Randy Singh of Kalsnet (KNet) Consulting Group that 
showcases 20 real-world reasoning AI use cases in one dashboard, spanning finance, healthcare, legal, cybersecurity, manufacturing, HR, 
IT operations, and more. For each use case, it generates synthetic data (or accepts an uploaded CSV), visualizes it with Plotly, and sends 
a structured prompt to a live LLM (Groq or Google Gemini) which produces transparent, step-by-step reasoning rather than a black-box score. 
Every metric is documented with its formula and business relevance, and results can be exported instantly as PDF, Word, CSV, or text. Built with 
Streamlit, Pandas/NumPy, Plotly, python-docx, and ReportLab, the app serves as both a sales/teaching tool and a working prototype, letting technical 
and non-technical audiences alike see how AI reasoning applies across industries, test it on real client data, and walk
away with polished, ready-to-share deliverables.
